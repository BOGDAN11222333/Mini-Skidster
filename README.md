# MINI SKIDSTER

## Project Description
ESP32 controlled mini skid steer vehicle with articulated arm and bucket.

## Hardware
- ESP32 C3
- DRV8833 motor driver
- Two DC drive motors N20 300rpm
- Two servo motors MG90 and SG 90
- Rechargeable battery system

## Software
- Arduino IDE
- ESP32 Arduino Core
- MIT App Inventor

## Control
- Two-motor differential steering
- Arm up/down
- Bucket open/close
- Two-joystick phone interface

## Development Status
Hardware and firmware development in progress.
